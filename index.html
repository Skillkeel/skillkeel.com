Skillkeel

Guard hooks, tested skills and evals for Claude Code. Each skill ships with a fixture repo, graders and the unedited transcript of a real run, so you can read what it does before you install it.

Every call in the recording is the real hook fed the JSON Claude Code sends.

Starter, free and MIT

guard-bash refuses destructive shell commands (rm -rf on root paths, force-push without lease, git reset --hard, recursive rm hidden behind find -exec, git settings that run commands). secret-scan refuses file writes that contain credentials. session-start prints a short project brief. The tests, the eval cases and the per-version results are all in the repository.

How it works

  1. Install the plugin with the two slash commands above, or unzip the Gumroad download into the project. Everything runs on your machine; no hook in either product makes a network call.
  2. Claude Code hands every Bash, Write and Edit call to the hooks as JSON before it runs them. A hook that refuses exits 2 and prints why, and Claude reads that text.
  3. The refusals are specific: a recursive delete hidden behind find -exec, a force push without a lease, a credential on its way into a file. Each one names its rule and the environment variable that turns it off for the session.
  4. The skills do the repeatable work: changelogs, PR descriptions, reviews, migrations. Each was run against a fixture repository before it shipped, and the unedited transcript of that run is in the download.

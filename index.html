Skillkeel

Guard hooks, tested skills and evals for Claude Code. Each skill ships with a fixture repo, a list of expected results and the unedited transcript of a real run, so you can read what it does before you install it.

Starter, free and MIT

Three hooks and eight repo skills. guard-bash refuses destructive shell commands (rm -rf on root paths, force-push without lease, git reset --hard, recursive rm hidden behind find -exec). secret-scan refuses file writes that contain credentials. session-start prints a short project brief. 44 hook tests, 8 skill evals with transcripts.
